# Codex Switch5 使用说明

Codex Switch5 用于在 Mac 上管理和切换 Codex 账号、查看剩余额度与本机 Token 用量。第一次使用，从下面的安装步骤开始；需要查找数据文件时，可直接跳到文末。

## 安装与首次打开

1. 从[下载页面](https://github.com/justamanm/codex-switcher/releases/tag/latest)获取 DMG。需要 macOS 14 或更新版本。
2. 打开 DMG，将 Codex Switch5 拖入“应用程序”，再从“应用程序”打开。
3. 应用会自动识别本地已登录账号与支持的账号存档。已有账号会出现在“账号”页；没有账号时，点击“增加账号”。

首次查询额度需要一点时间。“—”表示暂时没有额度数据，不代表额度为零。

当前构建采用临时签名。如果 macOS 阻止打开，确认下载来自本项目后，到“系统设置 → 隐私与安全性”查看是否提供“仍要打开”，按系统提示操作。

## 添加与切换账号

### 添加另一个账号

1. 点击右上角“增加账号”。
2. 按弹窗提示继续。应用会根据本机安装情况打开登录入口，或提示执行 `codex login`。
3. 完成目标账号的登录，并等待应用识别、保存结果。登录过程中保持 Switch5 运行。

增加账号需要安装 ChatGPT 或 Codex CLI；两者都没有时，应用会在修改账号文件前停止。仅切换已有账号不要求安装 ChatGPT。

不想继续时，使用弹窗中的“取消”，等待原账号恢复完成，不要直接结束进程。

### 切换到已有账号

1. 在“账号”页查看当前账号和推荐备用账号的额度。
2. 点击中间的“切换”，或点击账号列表中目标账号右侧的“切换”。
3. 按确认窗口的提示完成操作，检查“正在使用”是否已变为目标账号。

使用 Codex CLI 时，切换或新增账号前先退出相关会话，操作完成后重新打开，避免旧会话继续使用原来的登录状态。推荐账号只是方便选择，也可以自行选择其他账号。

### 登录失效

账号出现“重新登录”时，点击该入口并按提示完成登录。重新登录期间同样保持 Switch5 运行；取消时等待恢复完成。

## 整理账号与查看额度

账号列表同时展示 **5 小时剩余额度、周剩余额度和各自的重置时间**。百分比表示剩余额度；标有“上次记录”的数据需要刷新后再判断。

| 想做什么 | 操作入口 |
| --- | --- |
| 刷新全部账号 | 右上角“刷新” |
| 只刷新一个账号 | 该账号右侧的刷新图标 |
| 给账号起便于辨认的名称 | 账号右侧“…” → “设置别名” |
| 调整账号所属分组 | “…” → “更换分组” |
| 创建或管理分组 | 列表上方“分组” → “管理分组” |
| 按分组展示账号 | “分组” → “按分组显示” |
| 手动调整顺序 | 拖动账号左侧的拖动柄；需要时先在“排序”中恢复手动排序 |
| 按规则排列账号 | 列表上方“排序” |
| 查看账号信息 | “…” → “查看账号信息” |

“…”中的“移除账号”会在确认后将账号凭据移到废纸篓，**并非只隐藏列表项**。它与卸载 Switch5 是不同操作。

## 查看用量统计

进入顶部“用量统计”，再选择下面的页面。

### 统计信息

- 顶部显示今日、本周、本月的 Token 总量与 API 等值估算金额。
- 点击任意卡片的“Token 明细”，可同时展开或收起三个周期的明细。输入、输出为主要数据，缓存、推理和自动审查为补充数据。
- 在“历史 Token 用量”中选择每日、每周或每月。图表可左右拖动浏览；通过“查看时段”选择具体时段，查看对应 Token 与金额。

### 账号明细

按账号查看 5 小时额度周期、周额度周期，以及今天、本周、本月的用量。周期下方显示开始与重置时间；通过右上角“账号排序”选择比较的时间范围。

### 使用习惯

在右侧选择本周、本月或最近 30 天，查看不同时段的 Token 分布、额度观察和采样记录。柱高表示该小时的累计 Token，柱顶数字表示有用量的天数。

这些是已有记录的统计，不是工作时长记录，也不会据此自动安排账号切换。金额是 API 等值估算，不是订阅账单；详细计算方式见[统计来源与计算说明](#统计来源与计算说明)。

## 切换记录与设置

“切换记录”可分别查看账号操作与分组变更。账号切换、添加或重新登录后，可以在这里回看结果。

点击左上角齿轮打开设置，可选择中文或英文，并启用自动刷新、设置刷新间隔。自动刷新用于更新额度，不代表自动切换账号。

## 常见问题

| 遇到的问题 | 建议处理方式 |
| --- | --- |
| 首次打开没有账号 | 先通过“增加账号”完成登录。应用只识别支持的本地登录凭据，不会列出所有曾在浏览器中登录的账号 |
| 已登录 Codex，却没有显示 | 确认凭据位于当前 macOS 用户的 `~/.codex/`；当前不跟随自定义 `CODEX_HOME`，仅 API Key 的凭据也不在支持范围内 |
| 额度显示“—”或停留在上次记录 | 点击刷新，查看是否有查询失败或重新登录提示；不要将缺少数据理解为额度耗尽 |
| 没有推荐备用账号 | 刷新账号额度，检查其他账号是否可用、是否需要重新登录 |
| 切换后 CLI 仍显示旧账号 | 退出旧的 CLI 会话，再重新打开 |
| Token 与额度变化不一致 | Token 来自本机会话；额度来自服务端查询，其他设备也可能消耗额度，两者不是同一种统计 |
| 刚安装就有历史 Token | 本机已有 Codex 会话可以用于统计，首次安装 Switch5 不等于没有历史数据 |
| 使用习惯不同时间范围结果相同 | 现有记录可能都落在这些范围内；额度观察需要逐步积累 |
| 登录被中断或数据读取报错 | 按应用提示恢复；保留原文件与错误信息，不要通过删除凭据来尝试修复 |

仍无法解决时，可[反馈问题](https://github.com/justamanm/codex-switcher/issues)，附上操作步骤、错误提示与应用版本。截图请遮盖个人账号信息，不要提交登录凭据文件。

## 更新与卸载

更新时退出应用，将新版本拖入“应用程序”替换旧版本。账号凭据、分组、设置和统计记录保存在应用包之外，通常会继续保留。

仅将 Codex Switch5 应用移到废纸篓，会保留原有本地账号凭据，不会因此影响 ChatGPT／Codex 的登录与使用；也不会自动切回之前的账号。本应用的设置与统计记录同样保留，重新安装后可继续读取。

如果使用第三方卸载工具，删除范围取决于勾选项。具体文件归属与删除影响见下方的[本地文件与数据保存](#本地文件与数据保存)。

## 统计来源与计算说明

统计页展示今日、本周、本月和各账号周期用量。输入、输出是主要数据；缓存和推理作为补充展示。自动审查用量单独显示，不计入 Token 总数；金额也不包含自动审查，星号表示有其他用量无法估算。金额和完整周额度预测按 API 等值价格估算，不是订阅的实际账单。

Token 来自本机 Codex 会话记录；额度来自本应用的查询。登录凭据与统计记录保存在本机，但查询额度及刷新登录令牌需要连接 OpenAI 服务。

“使用习惯”可查看本周、本月和最近 30 天。柱高表示该小时累计 Token，柱顶数字表示有用量的天数。额度观察只使用同账号的有效查询间隔，排除超过 30 分钟、查询失败、跨重置和额度回升等情况。查询间隔包含空闲，其他设备也可能消耗额度，因此观察值不代表实际工作时长。

应用查询额度时记录结果，原始历史追加保存；损坏时停止追加并提示，不覆盖原文件。额度观察需要逐步积累；不同时间范围包含相同现有记录时，结果可能相同。已有本机会话可用于重新生成 Token 统计，不能将首次安装等同于没有历史用量。

## 本地文件与数据保存

文中的 `~` 表示当前 macOS 用户的主目录。

本应用先从 `~/.codex/` 识别登录账号，再读取自己的额度、分组和历史记录。应用程序与用户数据分开保存，删除 `.app` 不等于清除账号数据。

### Codex 原有目录与文件

目录：`~/.codex/`。

| 路径 | 归属与来源 | 本应用如何使用 |
| --- | --- | --- |
| `auth.json` | Codex 原有的当前登录凭据文件，由登录流程生成 | 读取当前身份；切换时替换其内容或文件；刷新登录令牌时可能更新它 |
| `sessions/` | Codex 原有的会话记录目录 | 读取会话中的 Token 用量，不移动原始会话 |
| `archived_sessions/` | Codex 原有的归档会话目录 | 读取会话中的 Token 用量，不移动原始会话 |

`auth.json` 虽然属于 Codex 原有文件，但本应用会操作它，不是只读。其余 Codex 文件，例如 `config.toml`，不属于 Switch5 的私有数据，不应为了重置 Switch5 一并移走。

当前账号扫描使用固定的 `~/.codex/` 路径，不会因为设置了 `CODEX_HOME` 就改用另一个目录。仅有 API Key、无法解析或没有 `tokens.access_token` 的文件，不会作为当前支持的登录账号显示。

### Codex 登录凭据存档与切换临时文件

以下也位于 `~/.codex/`，其中账号存档的内容仍是 Codex 登录凭据，Switch5 通过重命名保存和切换；它们不属于 Switch5 的私有统计数据。带账号名的后缀是切换工具采用的命名方式，不代表 Codex 自身会自动生成这些存档。

| 文件 | 用途 |
| --- | --- |
| `auth.json.<账号名>` | Codex 登录凭据的存档；本应用通过重命名管理，也可识别兼容工具留下的同格式存档 |
| `.codex-switch5-auth-<UUID>` | 切换过程中暂存活动凭据 |
| `.codex-switch5-stale-<UUID>` | 切换过程中暂存旧存档 |

不能仅凭文件名确定某个存档一定由本应用创建。`auth.json.bak`、`auth.json.hub`、`auth.json.hub.*` 被账号扫描排除，不应当作 Switch5 账号列表来处理。

临时凭据文件通常只在操作期间存在；若异常退出后有残留，不要直接删除，应先确认登录恢复状态。

### 本应用的数据目录

目录：`~/Library/Application Support/Codex Switch5/`。

| 文件 | 来源与用途 |
| --- | --- |
| `account_usage.json` | 本应用生成：最近一次查询的账号额度 |
| `account_aliases.json` | 本应用生成：账号别名 |
| `codex_switch5_account_groups.json` | 本应用生成：分组与账号所属分组 |
| `.active-auth-profile` | 本应用生成：当前账号名称标记 |
| `codex_switch5_usage_history.jsonl` | 本应用生成：额度查询、账号变更等历史事件 |
| `codex_switch5_token_usage.json` | 本应用生成：Token 统计、读取进度等状态 |
| `codex_switch5_token_usage.pre-timeline-backup.json` | 本应用旧版迁移备份；不一定存在 |
| `codex_switch5_switch_history.json` | 本应用生成：切换、登录等操作记录 |
| `codex_switch5_weekly_quota_projection.json` | 本应用生成：周额度估算数据 |
| `.codex-switch5-addition-pending.json` | 本应用生成：尚未完成的新增账号操作恢复记录，按需存在 |
| `.codex-switch5-reauthentication-pending.json` | 本应用生成：尚未完成的重新登录操作恢复记录，按需存在 |

旧版本曾把此表中的文件放在 `~/.codex/` 中。启动时，如果旧文件存在而新目录中没有对应文件，本应用会将其移动到新目录；新目录已有文件时不会覆盖。

旧文件可能在下次启动时迁移到新目录；排查数据来源时，应同时检查旧位置。

### 系统偏好设置

文件：`~/Library/Preferences/local.justaman.codex-switch5.plist`。

由 macOS 为本应用管理，保存以下内容：

- 语言、自动刷新开关与间隔。
- 账号手动顺序、排序规则、分组显示开关。
- 统计页排序选项。
- 当前账号名称及迁移标记。

macOS 会缓存偏好设置，直接修改文件不一定立即生效；应通过系统提供的偏好设置接口管理。

### 应用程序与构建产物

| 位置 | 内容 |
| --- | --- |
| `/Applications/Codex Switch5.app` | 通常安装位置；用户也可以选择其他位置 |
| `<项目目录>/dist/Codex Switch5.app` | 当前项目构建的本地应用 |
| `<项目目录>/dist/Codex-Switch5.dmg` | 打包脚本生成的安装包；不会随每次应用构建自动更新 |
| `.app/Contents/MacOS/CodexSwitch5` | 可执行程序 |
| `.app/Contents/Resources/AppIcon.icns`、`AppIcon.png` | 应用图标 |
| `.app/Contents/Info.plist`、`PkgInfo` | 应用名称、版本、标识等信息 |

这些应用包内部文件不包含用户账号存档、分组和使用记录。

### 删除应用会删除什么

| 操作 | 影响 |
| --- | --- |
| 只把某一份 `.app` 移到废纸篓 | 只移走该应用包及包内程序、图标等文件；数据目录、偏好设置、凭据和会话记录仍在 |
| 清空该应用所在的废纸篓 | 删除废纸篓中的应用包；不会因此自动清除上述外部数据 |
| 删除 DMG | 只删除安装包，不删除已安装应用和用户数据 |
| 重新复制 `.app` 覆盖旧版本 | 通常保留外部数据，下次启动继续读取 |
| 使用第三方卸载工具并选择关联文件 | 取决于工具和用户勾选项，可能同时清除数据目录和偏好设置，不能一概保证保留 |

本应用没有“删除 `.app` 时自动清理外部数据”的卸载流程。普通删除应用不会自动删除 `~/.codex/` 中的登录凭据。


### 旧名称兼容

当前程序、模块及新数据文件统一使用 Codex Switch5。首次启动会将数据目录或 `~/.codex/` 中旧的 `codex_switcher_*`、`.codex-switcher-*` 数据文件迁移到对应新名称；目标已经存在时不覆盖。旧偏好域 `local.justaman.codex-switcher` 的设置只迁移一次，旧域保留作兼容备份。普通删除应用仍会保留 `~/Library/Application Support/Codex Switch5/`。

GitHub 仓库地址与本地项目目录不随产品改名自动变化，因此相关链接和实际路径保留原名。
