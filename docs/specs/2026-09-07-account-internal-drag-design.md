# 账号列表应用内拖动设计

## 目标

账号列表拖动时不再使用 macOS 的系统拖放预览。拖动中的账号卡片在应用界面内跟随鼠标，其他账号卡片实时让位；松开鼠标后立即落到目标位置，不出现重复卡片、白色占位条或回弹。

## 范围

- 仅修改“账号”页的手动排序。
- 保留现有六点拖动把手、账号卡片样式、账号操作按钮和手动排序持久化。
- 不改变 Token 统计页的排序，也不增加失效账号的位置限制。

## 交互与数据流

1. 用户在六点把手按下并移动超过最小距离后，开始应用内拖动。
2. 原卡片保留一个透明占位位置；应用内浮层显示缩小后的完整账号卡片，并随鼠标垂直移动。
3. 根据浮层中心点所在位置计算插入索引，其他卡片用短动画让出位置；拖动期间只维护临时顺序，不写入偏好设置。
4. 松开鼠标时，将临时顺序一次写入 `accountManualOrder`；取消或离开列表时恢复开始拖动前的顺序。

## 实现边界

- 删除账号把手上的 `onDrag` 与列表上的 `onDrop`/`DropDelegate`，避免系统预览参与。
- 使用 `DragGesture`、行框架信息和覆盖层计算当前位置与临时顺序。
- 将排序状态拆为“已保存顺序”和“当前拖动临时顺序”，避免刷新或界面更新覆盖拖动结果。
- 对按钮区域保持原有点击行为；只有拖动把手启动手势。

## 验收

- 从任意账号拖到任意两行之间，松手后位置正确且刷新后仍保留。
- 松手的任一时刻只显示一张该账号卡片。
- 拖动经过账号时，其余卡片连续让位，不留下旧位置空洞。
- 点击拖动把手但未移动不改变排序，也不触发账号操作。
