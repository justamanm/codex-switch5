# 模型价格与金额图表设计

## 问题

最近记录主要使用 `gpt-6-sol`，但现有价格表没有这个模型；`gpt-6-luna` 也没有配置。结果会出现部分金额无法估算，界面用星号提示，但金额不完整。历史图表的柱高使用 Token 总数，金额只显示在柱顶，因此金额差异不会反映到柱高。

## 方案

- 按 API 等值价格补充 `gpt-6-sol` 和 `gpt-6-luna`：
  - `gpt-6-sol`：输入 2、缓存输入 0.2、输出 10 美元／百万 Token。
  - `gpt-6-luna`：输入 0.1、缓存输入 0.01、输出 0.5 美元／百万 Token。
- 保留已有模型价格和原始 Token 记录；统计刷新时自动重新计算金额。
- 历史图表的柱高改为估算金额，柱顶同时显示金额和 Token 数量。
- 金额含有未知模型时保留星号；完全无法估算时显示“暂无法估算”，不显示虚假的 0 美元。
- 金额计算继续区分未缓存输入、缓存输入、缓存写入和输出；自动审查用量不计入金额。

## 影响范围

修改模型价格表、统计页历史图表和相关中英文说明。不修改数据库结构，不改原始记录，不影响账号额度、切换和登录功能。

## 验证

- 新模型价格计算覆盖输入、缓存输入、缓存写入和输出。
- 未知模型仍返回无法估算。
- 历史图表使用金额作为纵轴，Token 数量仍可在柱顶和时段详情中查看。
- 调试检查、发布检查、正式应用构建和实际统计页面验证通过。
