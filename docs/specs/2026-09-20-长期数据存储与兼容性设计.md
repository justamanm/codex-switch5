# Codex Switch5 长期数据存储与兼容性设计

## 目标

Codex Switch5 持续使用数月或一年后，仍然能够快速启动、增量读取 Token 记录、统计用量，并安全升级本地数据格式。

本次只改造 Switch5 自己的统计和配置存储，不改变 Codex 的会话文件，不把认证令牌复制到新数据库。

## 当前问题

1. Token 会话文件已经是按位置增量读取，但累计事件全部保存在一个 JSON 文件中，每次扫描都会整份解码和重写。
2. 用量页按账号和时间周期多次遍历所有 Token 事件，数据越多，页面计算越慢。
3. 额度历史虽然追加写入 JSONL，但启动和学习统计仍会加载全部记录。
4. 大部分自有 JSON 没有格式版本号，无法安全区分旧格式、当前格式和未来格式。
5. 额度刷新允许秒级频率，会不必要地放大网络请求、历史文件和限流风险。

## 方案选择

### 选定：SQLite 持久化

macOS 自带 SQLite。将可持续增长的 Token 事件、额度历史、账号切换时间线和会话读取位置放入同一个本地数据库。

原因：

- 只插入新数据，不重写全部历史。
- 可以按账号、时间和模型建立索引。
- 可以直接在数据库内汇总今日、本周和本月数据。
- SQLite 自带事务和格式版本管理，比多个无版本 JSON 更适合持续升级。

### 未选方案

- 继续使用单个 JSON：开发量最小，但整份重写问题无法根治。
- 分片 JSONL：可以降低单文件大小，但仍要自行处理索引、去重、升级和跨文件统计。

## 数据设计

数据库文件位于 Switch5 的 Application Support 目录，名称为 `codex_switch5.sqlite3`。

数据表：

- `token_events`：保存 Token 事件，事件 ID 唯一，按账号和时间建立索引。
- `session_cursors`：保存每个会话文件的完整路径、已读位置、文件标识和当前模型。
- `account_activations`：保存账号激活时间线，用于把 Token 事件归属到正确账号。
- `usage_history`：保存额度观察、查询失败和切换结果。
- `daily_token_totals`：按日期、账号和模型保存历史汇总，支持长期统计。

通过 SQLite `PRAGMA user_version` 保存格式版本。每次版本变更都在事务内逐级升级，不跳过中间版本。

## 旧数据迁移

1. 首次打开新版本时创建数据库。
2. 在一个事务内导入 `codex_switch5_token_usage.json` 和 `codex_switch5_usage_history.jsonl`。
3. 导入成功后记录迁移标志，原文件保留为只读备份，不直接删除。
4. 导入中断时回滚事务，下次启动可以安全重试。
5. 数据库版本比当前应用更新时，应用停止写入并明确提示，不用旧结构覆盖新数据。

## Token 扫描流程

1. 枚举会话文件，但只打开文件大小或标识发生变化的项。
2. 从已读位置开始解析完整行。
3. 在同一事务内插入新 Token 事件并更新读取位置。
4. 文件被截断或替换时，根据文件标识从头重新扫描；事件唯一 ID 防止重复。
5. 账号切换和扫描使用同一串行化写入通道，防止时间线和 Token 归属产生竞争。

## 统计和保留策略

- 今日、本周、本月和指定时间段使用 SQL 汇总，不再为每个页面元素扫描全部 Swift 数组。
- 最近 90 天保留详细 Token 事件和额度记录。
- 90 天之前的 Token 数据保留每日汇总，不保留单次事件。
- 额度历史保留每日首次、最后一次和发生变化的观察，失败记录按小时汇总。
- 只在迁移或日常维护成功后清理数据，且整个过程在事务内完成。

## 额度刷新和认证

- 额度自动刷新最小间隔为 60 秒，界面不再允许更短的网络查询周期。
- 多账号刷新使用有限并发，最多同时查询 3 个账号。
- 单个账号失败不中断其他账号，保留已成功结果。
- 临时网络失败按退避时间重试，认证失效则立即提示重新登录。
- 继续以 Codex `auth.json` 及账号存档为凭据唯一来源，Switch5 数据库不保存 access token 或 refresh token。

## 错误处理

- 数据库或迁移失败时，旧文件保持不变，应用显示可理解的错误。
- 个别会话行无法解析时记录计数并继续，不中断其他文件。
- 缓存统计可以重建；原始事件和读取位置不得在错误时静默清空。

## 测试标准

- 旧 JSON/JSONL 导入前后的事件数、账号归属和统计结果一致。
- 重复迁移、重复扫描和文件移动不会产生重复事件。
- 模拟 1000 个会话文件、100 万条 Token 事件和 500 万条额度记录。
- 统计查询不随全部历史线性扫描 Swift 对象。
- 对数据库版本过新、数据损坏、会话文件截断和单账号网络失败都有自动检查。

## 代码改动评估

本次是新增多于删除的中等规模改造。新增的主要是 SQLite 存储、格式升级、旧数据迁移和压力测试；已有的会话解析、账号识别和界面展示尽量保留。迁移稳定后，可以删除整份 JSON 重写和全量数组统计代码。
