# 账号备注设计

## 目标

账号名称已经支持鼠标悬浮查看用户名和邮箱，因此移除重复的“查看账号信息”菜单项。账号名称右侧增加备注入口，备注保存后显示在悬浮信息的用户名和邮箱下方。

## 界面与交互

- 删除账号“…”菜单中的“查看账号信息”及对应弹窗。
- 在账号名称右侧放置 `square.and.pencil` 图标按钮。
- 图标始终使用普通次要颜色，不根据是否存在备注改变颜色。
- 图标提供“添加备注”或“编辑备注”的辅助功能说明，但视觉样式保持一致。
- 点击图标后打开单行备注编辑窗口。
- 已有备注时，输入框自动填入当前内容。
- 编辑窗口只提供“取消”和“保存”，不提供单独的“清除备注”按钮。
- 输入内容去除首尾空白后保存；内容为空时删除该账号备注。
- 账号名称的悬浮信息依次显示用户名、邮箱；存在备注时在下方追加“备注：内容”。
- 悬浮信息没有备注时不显示空白备注行。

移除“查看账号信息”后，账号名称继续向辅助功能提供用户名、邮箱和备注文本，避免详细信息只能依赖鼠标悬浮。

## 数据保存

备注使用账号内部名称作为键，独立保存到：

`~/Library/Application Support/Codex Switch5/account_notes.json`

文件内容为账号名称到备注文本的映射。备注不写入 `~/.codex/`，不修改 Codex 凭据或会话文件。

保存规则：

- 应用启动时读取全部备注。
- 保存备注时原子写入完整映射，并设置仅当前用户可读写的权限。
- 移除账号时同步删除对应备注。
- 备注文件不存在时按空备注处理。
- 文件读取失败时不影响账号识别和切换；保存失败时保留当前界面内容并显示错误。

## 代码边界

- `AppModel` 管理备注映射、当前编辑账号、输入内容和保存操作。
- 独立存储类型负责备注文件的读取与保存，避免把备注格式耦合到别名文件。
- `DashboardView` 只负责展示备注图标、编辑窗口和传递操作。
- `HoverAccountName` 接收完整悬浮信息，不直接读取存储。
- `Localization` 提供中英文的备注、编辑和错误文案。

## 文档更新

中英文使用说明需要同步更新：

- 账号操作表增加备注入口。
- 删除“查看账号信息”入口。
- 本地数据文件表增加 `account_notes.json`。
- 明确备注只保存在 Switch5 应用数据目录。

## 验证

- 核心检查覆盖备注文件不存在、保存、重新读取、修改、空内容删除及损坏文件处理。
- SwiftUI 构建确认账号行、编辑窗口和本地化文案能够编译。
- 实际应用检查备注图标位置、原内容自动填入、空内容删除和悬浮信息顺序。
- 检查“查看账号信息”不再出现在账号菜单中。
- 检查备注保存后重启应用仍能读取。
- 检查 `git diff --check` 和实际新增、删除行数。

## 改动量评估

本次预计新增多于删除。新增内容主要是备注存储、编辑状态、图标按钮、编辑窗口、本地化和检查；删除内容主要是重复的“查看账号信息”菜单项及其弹窗状态。
