# 账号组合排序设计

## 目标

在账号页增加可保存的组合排序。用户可以同时设置多个排序条件，每个条件独立选择升序或降序，并明确调整优先级。

## 排序规则

- 可选字段为：周重置时间、周额度、5h 重置时间、5h 额度。
- 规则从上到下依次比较，前一项相同时才使用下一项。
- 每项可独立选择升序或降序。
- 所有条件都相同时保持当前手动顺序，避免列表无故跳动。
- 开启按分组显示时，只排序组内账号，不改变分组顺序。
- 账号登录失效状态不参与排序。
- 缺少重置时间的账号统一排在该条件最后，不受升降序影响。

## 界面

- “所有账号”第一行中，在“按分组显示”左侧增加“排序”按钮。
- 点击后打开排序规则弹窗，逐行显示字段和升降序。
- 支持添加、删除规则，并用上下按钮调整优先级。
- 同一个字段最多出现一次；四个字段都已使用时不能继续添加。
- “恢复手动排序”清空全部规则。
- 存在排序规则时禁用账号拖动，并提示先清空排序规则。
- 宽屏的“5h额度”和“周额度”继续显示在独立第二行。

## 保存与验证

- 排序规则使用应用本地配置保存，重启后恢复。
- 验证单项升降序、多项优先级、时间缺失、数值相同、组内排序、清空规则和重启恢复。
- 每次修改后重新编译并重启应用，在最小宽度和普通非全屏宽度检查。
