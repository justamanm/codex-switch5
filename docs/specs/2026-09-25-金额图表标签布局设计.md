# 金额图表标签布局设计

## 问题

历史用量图表在每根柱子上同时显示金额和 Token 数量。每日数据较多时，标签宽度超过柱子之间的间距，导致相邻文字互相覆盖。

## 方案

- 柱高继续表示 API 等值估算金额。
- 柱顶只显示金额，不显示 Token 数量。
- Token 数量继续显示在图表下方的“查看时段”详情中。
- 每日、每周和每月图表统一使用相同规则。
- 不修改金额计算、原始 Token 记录和数据库结构。

## 验证

- 每日图表的柱顶金额之间不再重叠。
- 每周和每月图表仍能正常显示金额。
- 选择任一时段后，下方仍显示完整的 Token 数量和金额。
- 正式应用构建并实际打开检查。
