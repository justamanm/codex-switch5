# 账号手动分组设计

## 目标

为账号列表增加本地手动分组，同时修正“失效”标记位置。分组只用于整理和显示账号，不修改账号凭据，也不影响账号切换、额度刷新和 Token 统计。

## 数据规则

- 每个账号最多属于一个分组，也可以不属于任何分组。
- 分组名称和账号所属关系单独保存在应用本地配置中。
- 分组按创建顺序显示，组内账号继续沿用当前账号排序。
- 删除分组时不删除账号；该组账号全部转为“未分组”。
- 已不存在账号的旧关系在读取时自动忽略。
- 分组名称去除首尾空格后不能为空，也不能与现有分组重名。

## 操作入口

账号页“所有账号”标题行增加两个入口：

- “按分组显示”开关：关闭时保持当前平铺列表；开启后按分组显示，同组账号连续排列并显示分组标题，“未分组”位于最后。
- “管理分组”按钮：打开管理窗口，可创建、改名和删除分组，也可选择一个分组后勾选多个账号批量加入。账号加入新分组时自动离开原分组。

管理窗口中的删除操作需要确认，并明确提示账号会转为“未分组”。

## 添加账号

添加账号窗口增加一个可选分组选择框，默认选择“未分组”。登录成功并识别到新账号后，再保存该账号的分组关系。取消添加、登录失败或恢复旧账号时，不改变任何分组关系。

## 列表显示

- “失效”标记显示在账号名称右侧。
- 空间不足时优先保留“失效”标记，账号名称使用省略号截断。
- 按分组显示只改变账号页的排列，不改变 Token 统计页的排序和内容。
- 当前账号仍使用现有高亮样式，并可正常拖动；按分组显示时拖动只调整组内顺序，不跨组移动，跨组移动通过分组管理完成。

## 异常处理

- 本地分组配置读取失败时显示未分组列表，不阻止应用启动和账号操作。
- 保存失败时保留界面原状态并显示错误，不假装操作成功。
- 删除账号后同步移除该账号的分组关系。

## 验证

- 创建、重名拦截、改名、删除分组。
- 批量选择账号加入分组，以及从原分组移动到新分组。
- 添加账号时选择分组、不选择分组、取消和失败路径。
- 平铺与按组显示切换，确认分组顺序、组内顺序和未分组位置。
- 删除分组后账号仍存在且进入未分组。
- 普通宽度与最小宽度下，“失效”始终位于账号名右侧且不会被截断。
- 重新编译并重启 `dist/Codex Switcher.app` 后确认分组数据仍然存在。
