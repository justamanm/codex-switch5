# Codex Switch5 使用说明

Codex Switch5 用于在 Mac 上管理和切换 Codex 账号、查看剩余额度与本机 Token 用量。第一次使用，从下面的安装步骤开始；需要查找数据文件时，可直接跳到文末。

## 安装与首次打开

1. 从[下载页面](https://github.com/justamanm/codex-switch5/releases/tag/latest)获取 DMG。需要 macOS 14 或更新版本。
2. 打开 DMG，将 Codex Switch5 拖入“应用程序”，再从“应用程序”打开。
3. 应用会自动识别本地已登录账号与支持的账号存档。已有账号会出现在“账号”页；没有账号时，点击“增加账号”。

首次查询额度需要一点时间。“—”表示暂时没有额度数据，不代表额度为零。

此安装包使用临时签名。如果 macOS 阻止打开，确认下载来自本项目后，到“系统设置 → 隐私与安全性”查看是否提供“仍要打开”，按系统提示操作。

## 添加与切换账号

### 添加另一个账号

1. 点击右上角“增加账号”。
2. 按弹窗提示继续。应用会根据本机安装情况打开登录入口，或提示执行 `codex login`。
3. 完成目标账号的登录，并等待应用识别、保存结果。登录过程中保持 Switch5 运行。

增加账号需要安装 ChatGPT 或 Codex CLI；两者都没有时，应用会在修改账号文件前停止。仅切换已有账号不要求安装 ChatGPT。

不想继续时，使用弹窗中的“取消”，等待原账号恢复完成，不要直接结束进程。

### 切换到已有账号

1. 在“账号”页查看当前账号和推荐备用账号的额度。
2. 点击中间的“切换”，或点击账号列表中目标账号右侧的“切换”。
3. 按确认窗口的提示完成操作，检查“正在使用”是否已变为目标账号。

使用 Codex CLI 时，切换或新增账号前先退出相关会话，操作完成后重新打开，避免旧会话继续使用原来的登录状态。推荐账号只是方便选择，也可以自行选择其他账号。

### 登录失效

账号出现“重新登录”时，点击该入口并按提示完成登录。重新登录期间同样保持 Switch5 运行；取消时等待恢复完成。

## 什么时候需要保持应用运行

**切换完成后，可以退出 Switch5，继续使用 ChatGPT／Codex CLI。** Switch5 不需要作为中间程序持续运行；退出不会撤销已经完成的账号切换。使用 CLI 时，仍需在切换后重新打开会话。

| 使用场景 | 是否需要保持运行 | 原因 |
| --- | --- | --- |
| 正在添加账号或重新登录 | 需要 | 应用需要等待登录结果，核对身份并保存账号 |
| 正在切换账号，或取消登录后恢复原账号 | 需要 | 等待完成提示，避免中断凭据保存与恢复 |
| 已完成切换，只想继续使用 ChatGPT／Codex CLI | 不需要 | 登录凭据已经写入本地；客户端可继续独立使用 |
| 希望额度自动刷新、持续积累额度观察 | 需要，并启用自动刷新 | 退出后不再定时查询，期间的额度变化不能事后完整补回 |
| 希望及时发现登录失效 | 需要查询额度 | 应用只能在检测到失败时记录失效，退出期间无法发现；记录的是首次检测时间，不是服务端实际失效时间 |

保持运行不要求窗口一直在前台，可以切换到其他应用。需要持续记录时，不要使用“退出”或 `Command-Q`；电脑休眠或网络断开时也不能保证持续采样。

### 尽量通过 Switch5 切换账号

为了让切换记录和账号用量归属更完整，建议通过 Switch5 执行账号切换、添加和重新登录。应用会在这些操作前后处理统计与记录。

手动替换凭据、直接运行登录命令或使用其他切换工具，并不意味着 ChatGPT／Codex 一定无法使用，但 Switch5 可能无法还原完整的切换时间和过程，账号明细也可能归属不准确。尤其不要在 Switch5 正在登录或恢复时，用另一个工具同时修改凭据。

### 退出期间的统计会怎样

- **Token 记录**：重新打开后，可继续扫描仍保存在本机的 Codex 会话；不等于退出期间的 Token 一定丢失。但如果期间在外部切换过账号，不能保证准确还原每段用量属于哪个账号。
- **额度记录**：退出期间没有查询，重新打开只能取得届时的额度，无法补出每次变化和准确的失效时刻。
- **切换记录**：应用外发生的操作不保证补记。需要较完整的记录时，通过 Switch5 操作，并保持应用运行和自动刷新。

## 整理账号与查看额度

账号列表同时展示 **5 小时剩余额度、周剩余额度和各自的重置时间**。百分比表示剩余额度；标有“上次记录”的数据需要刷新后再判断。

| 想做什么 | 操作入口 |
| --- | --- |
| 刷新全部账号 | 右上角“刷新” |
| 只刷新一个账号 | 该账号右侧的刷新图标 |
| 给账号起便于辨认的名称 | 账号右侧“…” → “设置别名” |
| 调整账号所属分组 | “…” → “更换分组” |
| 创建或管理分组 | 列表上方“分组” → “管理分组” |
| 按分组展示账号 | “分组” → “按分组显示” |
| 手动调整顺序 | 拖动账号左侧的拖动柄；需要时先在“排序”中恢复手动排序 |
| 按规则排列账号 | 列表上方“排序” |
| 查看账号信息 | “…” → “查看账号信息” |

“…”中的“移除账号”会在确认后将账号凭据移到废纸篓，**并非只隐藏列表项**。它与卸载 Switch5 是不同操作。

### 额度刷新规则

| 触发方式 | 查询范围 | 是否访问网络 |
| --- | --- | --- |
| 启动应用 | 先显示本地缓存，再在后台刷新已识别的全部账号 | 是 |
| 点击右上角“刷新” | 全部已识别账号，每次最多同时查询 3 个 | 是 |
| 点击账号右侧刷新图标 | 只查询该账号 | 是 |
| 启用自动刷新 | 查询尚未标记为登录失效的账号，最短间隔为 1 分钟 | 是 |
| 到达已知的 5 小时额度重置时间 | Switch5 保持运行时，单独查询对应的有效账号 | 是 |
| 关闭自动刷新 | 每 5 分钟扫描一次本地新增 Token 记录；这个计时器不查询额度 | 否 |

自动刷新会等待本轮完成后再安排下一轮，不会让多轮额度查询互相重叠。临时网络错误、HTTP 429 或服务端错误最多重试两次。某个账号失败时，其他账号已成功取得的结果仍会保存；失败账号也不会因此清空最后一次有效额度。

凭证失效后，应用保留最后一次有效额度、重置卡数量和已经取得的重置卡到期时间，并提示重新登录。自动刷新会跳过已经标记为登录失效的账号；手动刷新仍可再次尝试。重新登录成功且重置卡详情查询成功后，才更新已保存的到期时间；服务确认没有重置卡时才清空到期时间。

## 查看用量统计

进入顶部“用量统计”，再选择下面的页面。

### 统计信息

- 顶部显示今日、本周、本月的 Token 总量与 API 等值估算金额。
- 点击任意卡片的“Token 明细”，可同时展开或收起三个周期的明细。输入、输出为主要数据，缓存、推理和自动审查为补充数据。
- 在“历史 Token 用量”中选择每日、每周或每月。图表可左右拖动浏览；通过“查看时段”选择具体时段，查看对应 Token 与金额。

### 账号明细

按账号查看 5 小时额度周期、周额度周期，以及今天、本周、本月的用量。周期下方显示开始与重置时间；通过右上角“账号排序”选择比较的时间范围。

### 使用习惯

在右侧选择本周、本月或最近 30 天，查看不同时段的 Token 分布、额度观察和采样记录。柱高表示该小时的累计 Token，柱顶数字表示有用量的天数。

这些是已有记录的统计，不是工作时长记录，也不会据此自动安排账号切换。金额是 API 等值估算，不是订阅账单；详细计算方式见[统计来源与计算说明](#统计来源与计算说明)。

## 切换记录与设置

“切换记录”可分别查看账号操作与分组变更。账号切换、添加或重新登录后，可以在这里回看结果。

点击左上角齿轮打开设置，可选择中文或英文，并启用自动刷新、设置刷新间隔。自动刷新用于更新额度，不代表自动切换账号；完整行为见[额度刷新规则](#额度刷新规则)。开启自动刷新时，Token 统计随额度查询更新；关闭后，每 5 分钟只扫描本地新增的 Token 记录，这个计时器不会查询网络额度。

## 常见问题

| 遇到的问题 | 建议处理方式 |
| --- | --- |
| 首次打开没有账号 | 先通过“增加账号”完成登录。应用只识别支持的本地登录凭据，不会列出所有曾在浏览器中登录的账号 |
| 已登录 Codex，却没有显示 | 确认凭据位于当前 macOS 用户的 `~/.codex/`；当前不跟随自定义 `CODEX_HOME`，仅 API Key 的凭据也不在支持范围内 |
| 额度显示“—”或停留在上次记录 | 点击刷新，查看是否有查询失败或重新登录提示；不要将缺少数据理解为额度耗尽 |
| 没有推荐备用账号 | 刷新账号额度，检查其他账号是否可用、是否需要重新登录 |
| 切换后 CLI 仍显示旧账号 | 退出旧的 CLI 会话，再重新打开 |
| Token 与额度变化不一致 | Token 来自本机会话；额度来自服务端查询，其他设备也可能消耗额度，两者不是同一种统计 |
| 刚安装就有历史 Token | 本机已有 Codex 会话可以用于统计，首次安装 Switch5 不等于没有历史数据 |
| 使用习惯不同时间范围结果相同 | 现有记录可能都落在这些范围内；额度观察需要逐步积累 |
| 登录被中断或数据读取报错 | 按应用提示恢复；保留原文件与错误信息，不要通过删除凭据来尝试修复 |

仍无法解决时，可[反馈问题](https://github.com/justamanm/codex-switch5/issues)，附上操作步骤、错误提示与应用版本。截图请遮盖个人账号信息，不要提交登录凭据文件。

## 卸载

仅将 Codex Switch5 应用移到废纸篓，会保留原有本地账号凭据，不会因此影响 ChatGPT／Codex 的登录与使用；也不会自动切回之前的账号。本应用的设置与统计记录同样保留，重新安装后可继续读取。

如果使用第三方卸载工具，删除范围取决于勾选项。具体文件归属与删除影响见下方的[本地文件与数据保存](#本地文件与数据保存)。

## 统计来源与计算说明

统计页展示今日、本周、本月和各账号周期用量。输入、输出是主要数据；缓存和推理作为补充展示。自动审查用量单独显示，不计入 Token 总数；金额也不包含自动审查，星号表示有其他用量无法估算。金额和完整周额度预测按 API 等值价格估算，不是订阅的实际账单。

Token 来自本机 Codex 会话记录；额度来自本应用的查询。登录凭据与统计记录保存在本机，但查询额度及刷新登录令牌需要连接 OpenAI 服务。

“使用习惯”可查看本周、本月和最近 30 天。柱高表示该小时累计 Token，柱顶数字表示有用量的天数。额度观察只使用同账号的有效查询间隔，排除超过 30 分钟、查询失败、跨重置和额度回升等情况。查询间隔包含空闲，其他设备也可能消耗额度，因此观察值不代表实际工作时长。

额度查询结果和单次 Token 用量记录保存在本地 SQLite 数据库。最近 90 天保留明细；更早的 Token 明细转为每日汇总，额度观察转为每日摘要。已有本机会话可用于重新生成 Token 统计，不能将首次安装等同于没有历史用量。

## 本地文件与数据保存

文中的 `~` 表示当前 macOS 用户的主目录。

本应用只在本地读取 `~/.codex/` 来识别登录账号，再读取保存在本机的额度、分组和历史记录。应用程序与用户数据分开保存，删除 `.app` 不等于清除账号数据。

### Switch5 会如何使用 `~/.codex/`

Codex 登录凭据和本机会话记录保存在 `~/.codex/`。Switch5 只在本地读取这个目录来识别账号并统计 Token，不会改写、移动或删除会话记录。Switch5 自己的额度、分组、设置和统计记录保存在 `~/Library/Application Support/Codex Switch5/`，不会写入 Codex 会话目录。

| 操作 | Switch5 会做什么 |
| --- | --- |
| 启动、识别账号、查看 Token 统计 | 只在本地读取 `auth.json`、账号存档及 `sessions/`、`archived_sessions/`；不会修改会话内容 |
| 查询额度 | 在本地读取对应凭据并连接 OpenAI 服务；不会上传凭据文件或本机会话文件。访问令牌失效且刷新成功时，会把更新后的令牌写回同一个凭据文件 |
| 切换账号 | 在 `auth.json` 与 `auth.json.<账号名>` 之间重命名凭据文件；切换逻辑不改写凭据内容，并在失败时尽量恢复原文件状态 |
| 增加账号或重新登录 | 归档和恢复现有凭据；新的 `auth.json` 由 ChatGPT 或 Codex CLI 登录流程生成。操作成功后可能清理被替换的账号存档 |
| 移除账号 | 确认后，将对应的 `auth.json.<账号名>` 移到废纸篓 |

凭据文件和本机会话文件不会作为文件上传。查询额度时，Switch5 只使用凭据中的访问令牌完成身份验证。

### Codex 原有目录与文件

目录：`~/.codex/`。

| 路径 | 归属与来源 | 本应用如何使用 |
| --- | --- | --- |
| `auth.json` | Codex 原有的当前登录凭据文件，由登录流程生成 | 在本地读取当前身份；切换时替换其内容或文件；刷新登录令牌时可能更新它 |
| `sessions/` | Codex 原有的会话记录目录 | 只在本地读取会话中的 Token 用量，不移动原始会话 |
| `archived_sessions/` | Codex 原有的归档会话目录 | 只在本地读取会话中的 Token 用量，不移动原始会话 |

`auth.json` 虽然属于 Codex 原有文件，但 Switch5 会按上表所列情况操作它。重置 Switch5 时，不要移动 `config.toml` 等其他 Codex 文件。

Switch5 只从当前 macOS 用户的 `~/.codex/` 查找账号，不会跟随自定义的 `CODEX_HOME`。仅有 API Key、文件无法读取或缺少 `tokens.access_token` 时，账号不会显示在列表中。

### Codex 登录凭据存档与切换临时文件

以下也位于 `~/.codex/`，其中账号存档的内容仍是 Codex 登录凭据，Switch5 通过重命名保存和切换；它们不属于 Switch5 的私有统计数据。带账号名的后缀是切换工具采用的命名方式，不代表 Codex 自身会自动生成这些存档。

| 文件 | 用途 |
| --- | --- |
| `auth.json.<账号名>` | Codex 登录凭据的存档；本应用通过重命名管理 |
| `.codex-switch5-auth-<UUID>` | 切换过程中暂存活动凭据 |
| `.codex-switch5-stale-<UUID>` | 切换过程中暂存旧存档 |

不能仅凭文件名确定某个存档一定由 Switch5 创建。`auth.json.bak`、`auth.json.hub`、`auth.json.hub.*` 不会显示在 Switch5 的账号列表中。

临时凭据文件通常只在操作期间存在；若异常退出后有残留，不要直接删除，应先确认登录恢复状态。

### 本应用的数据目录

目录：`~/Library/Application Support/Codex Switch5/`。

| 文件 | 来源与用途 |
| --- | --- |
| `account_usage.json` | 本应用生成：最近一次查询的账号额度 |
| `account_aliases.json` | 本应用生成：账号别名 |
| `codex_switch5_account_groups.json` | 本应用生成：分组与账号所属分组 |
| `.active-auth-profile` | 本应用生成：当前账号名称标记 |
| `codex_switch5.sqlite3` | 本应用主数据库：单次 Token 用量记录、读取进度、额度历史与长期汇总 |
| `codex_switch5.sqlite3-wal`、`codex_switch5.sqlite3-shm` | SQLite 运行期间可能出现的辅助文件 |
| `codex_switch5_switch_history.json` | 本应用生成：切换、登录等操作记录 |
| `codex_switch5_weekly_quota_projection.json` | 本应用生成：周额度估算数据 |
| `.codex-switch5-addition-pending.json` | 本应用生成：尚未完成的新增账号操作恢复记录，按需存在 |
| `.codex-switch5-reauthentication-pending.json` | 本应用生成：尚未完成的重新登录操作恢复记录，按需存在 |

### 系统偏好设置

文件：`~/Library/Preferences/local.justaman.codex-switch5.plist`。

由 macOS 为本应用管理，保存以下内容：

- 语言、自动刷新开关与间隔。
- 账号手动顺序、排序规则、分组显示开关。
- 统计页排序选项。
- 当前账号名称。

macOS 会缓存偏好设置，直接修改这个文件不一定立即生效。请在 Switch5 的设置中调整这些选项。

### 删除应用会删除什么

| 操作 | 影响 |
| --- | --- |
| 只把某一份 `.app` 移到废纸篓 | 只移走该应用包及包内程序、图标等文件；数据目录、偏好设置、凭据和会话记录仍在 |
| 清空该应用所在的废纸篓 | 删除废纸篓中的应用包；不会因此自动清除上述外部数据 |
| 删除 DMG | 只删除安装包，不删除已安装应用和用户数据 |
| 使用第三方卸载工具并选择关联文件 | 取决于工具和用户勾选项，可能同时清除数据目录和偏好设置，不能一概保证保留 |

本应用没有“删除 `.app` 时自动清理外部数据”的卸载流程。普通删除应用不会自动删除 `~/.codex/` 中的登录凭据。
