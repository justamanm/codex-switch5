# 额度百分比向下取整实施计划

> **执行要求：** 在当前会话中按任务顺序实施，每个任务完成后运行对应检查并使用英文提交信息。

**目标：** 将接口返回的已用额度换算为向下取整的剩余百分比，避免实际不足 1% 时显示为 1%。

**结构：** 在核心模块新增 `QuotaPercentage`换算器，`NativeAccountService` 调用该换算器，核心检查程序覆盖边界值。

**技术范围：** Swift 6、Foundation、Swift Package Manager。

## 全局约束

- 剩余额度统一向下取整。
- 结果限制在 0～100。
- 5 小时额度和周额度使用同一换算函数。
- 不修改已保存的历史数据。
- 不生成 DMG。
- Git 提交信息使用英文。

- [x] **步骤 2：运行检查并确认编译失败**

```bash

```

预期：因 `QuotaPercentage` 尚未定义而编译失败。

- [x] **步骤 3：实现向下取整换算器**

```swift
import Foundation

public enum QuotaPercentage {
    public static func remaining(fromUsedPercent usedPercent: Double) -> Int {
        max(0, min(100, Int((100 - usedPercent).rounded(.down))))
    }
}
```

- [x] **步骤 4：运行核心检查**

```bash
swift run --disable-sandbox CodexSwitch5CoreChecks
```

预期：新增边界检查和现有检查全部通过。

**依赖：**

- 调用 `QuotaPercentage.remaining(fromUsedPercent:)`。

- [x] **步骤 1：替换嵌套的四舍五入公式**

```swift
func remaining(_ value: [String: Any]) throws -> Int {
    guard let used = value["used_percent"] as? Double else {
        throw NativeAccountServiceError.invalidResponse
    }
    return QuotaPercentage.remaining(fromUsedPercent: used)
}
```
