# 账号资料编辑与弹窗焦点实施计划

> **执行要求：** 在当前会话中按任务顺序实施，每个任务完成后运行对应检查并使用英文提交信息。

**目标：** 将别名、备注和所属分组合并到账号名称旁的统一编辑弹窗，并使所有含输入框的弹窗及独立设置窗口打开时不自动聚焦输入框。

**结构：** `AppModel` 统一管理账号编辑草稿与保存；`DashboardView` 只保留一个账号编辑弹窗和一个编辑入口；新增小型 AppKit 桥接视图负责在窗口首次显示后清除系统自动产生的输入焦点。现有别名、备注和分组文件格式保持不变。

**技术范围：** Swift 6、SwiftUI、AppKit、Foundation、Swift Package Manager。

## 全局约束

- 账号编辑弹窗包含别名、备注和所属分组。
- 未设置别名时输入框保持空白，不用界面显示名称代填。
- 空别名或空备注保存后删除对应记录。
- 所属分组可选择现有分组或“未分组”。
- “…”菜单只保留“移除账号”。
- 弹窗首次显示时不自动聚焦输入框，之后的点击和键盘切换正常。
- 中英文界面和使用说明同步更新。
- 不新增数据文件，不修改 `~/.codex/`。
- 不生成 DMG。
- Git 提交信息使用英文。

**文件：**

**接口：**

```swift
@Published var editingAccount: String?
@Published var editingAlias = ""
@Published var editingNote = ""
@Published var editingGroupID: UUID?

func beginEditingAccount(_ account: String)
func cancelEditingAccount()
func saveAccountDetails()
```

- [x] **步骤 1：合并编辑状态**

删除 `editingNoteAccount`，由 `editingAccount` 唯一表示正在修改的账号。增加 `editingGroupID`。

- [x] **步骤 2：载入真实保存值**

`beginEditingAccount(_:)` 使用 `aliases[account] ?? ""`、`accountNotes[account] ?? ""` 和 `groupID(for:)` 填入草稿。不得调用 `displayName(for:)` 代填别名。

- [x] **步骤 3：合并保存行为**

`saveAccountDetails()` 去除别名和备注首尾空白，空值从对应字典移除；备注文件保存失败时保留编辑状态并显示错误。保存成功后调用现有分组分配能力，只在分组值改变时产生分组记录，最后清空编辑草稿。

- [x] **步骤 4：构建模型接口**

运行：

```bash
swift build --disable-sandbox
```

预期：模型接口与现有核心模块编译通过。

### 任务三：统一取消弹窗首次输入焦点

**文件：**

- 新建：`Sources/CodexSwitch5/InitialFocusReset.swift`
- 修改：`Sources/CodexSwitch5/DashboardView.swift`
- 修改：`Sources/CodexSwitch5/CodexSwitch5App.swift`

**接口：**

```swift
extension View {
    func clearsInitialTextFocus() -> some View
}
```

- [x] **步骤 1：实现可复用焦点清理器**

使用 `NSViewRepresentable` 放置透明 AppKit 视图。视图首次加入窗口后，在主线程下一轮调用 `window.makeFirstResponder(nil)`；每次视图实例只执行一次，不能持续抢走之后由点击或 Tab 产生的焦点。

- [x] **步骤 2：覆盖应用内弹窗**

把修饰器应用到修改账号、应用内设置和分组管理弹窗的根视图。切换确认和账号登录弹窗没有输入框，不应用该修饰器。

- [x] **步骤 3：覆盖独立设置窗口**

把修饰器应用到 `CodexSwitch5App.swift` 的设置表单根视图，确保从 macOS 菜单打开设置时查询间隔输入框不自动聚焦。

- [x] **步骤 4：构建焦点处理**

运行：

```bash
swift build --disable-sandbox
```

预期：SwiftUI 与 AppKit 桥接编译通过。
