# 账号备注实施计划

> **执行要求：** 按任务顺序实施，每个任务先增加检查，再完成最小实现并运行对应验证。

**目标：** 移除重复的“查看账号信息”菜单项，在账号名称右侧增加备注入口，并将备注持久保存在应用数据目录中。

**结构：** 新增独立的 `AccountNoteStore` 负责备注文件读写；`AppModel` 管理备注状态和编辑流程；`DashboardView` 负责图标、编辑窗口与悬浮信息展示。备注不写入凭据文件，不与别名文件共用数据结构。

**技术范围：** Swift 6、SwiftUI、Foundation、Swift Package Manager、现有 `CodexSwitch5CoreChecks`。

## 全局约束

- 备注文件固定为 `~/Library/Application Support/Codex Switch5/account_notes.json`。
- 备注输入为单行文本；保存前去除首尾空白，空内容表示删除备注。
- 已有备注自动填入编辑框，不提供单独的清除按钮。
- 备注图标始终使用普通次要颜色，不按状态变色。
- 备注只显示在用户名和邮箱下方，不常驻显示在账号列表行内。
- 删除“查看账号信息”菜单项，同时保留辅助功能读取账号详情的能力。
- 中英文界面和使用说明同步更新。
- Git 提交信息使用英文。

### 任务一：新增独立备注存储

**文件：**

- 新建：`Sources/CodexSwitch5Core/AccountNoteStore.swift`
- 修改：`Sources/CodexSwitch5CoreChecks/main.swift`

**接口：**

```swift
public struct AccountNoteStore: Sendable {
    public let url: URL
    public init(url: URL)
    public func load() throws -> [String: String]
    public func save(_ notes: [String: String]) throws
}
```

- [ ] **步骤 1：先增加备注存储检查**

在 `Sources/CodexSwitch5CoreChecks/main.swift` 增加：

```swift
func checkAccountNoteStore() throws {
    let root = FileManager.default.temporaryDirectory
        .appendingPathComponent("account-note-store-\(UUID().uuidString)")
    let url = root.appendingPathComponent("account_notes.json")
    let store = AccountNoteStore(url: url)

    precondition(try store.load().isEmpty)
    try store.save(["account-a": "主要账号"])
    precondition(try store.load() == ["account-a": "主要账号"])
    try store.save(["account-a": "工作账号", "account-b": "备用"])
    precondition(try store.load()["account-a"] == "工作账号")
    try store.save([:])
    precondition(try store.load().isEmpty)

    try Data("broken".utf8).write(to: url)
    do {
        _ = try store.load()
        preconditionFailure("损坏的备注文件必须返回错误")
    } catch {}
}
try checkAccountNoteStore()
```

- [ ] **步骤 2：运行检查并确认接口尚未存在**

运行：`swift run CodexSwitch5CoreChecks`

预期：编译失败，提示找不到 `AccountNoteStore`。

- [ ] **步骤 3：实现备注文件读写**

`AccountNoteStore` 在文件不存在时返回空字典；保存时创建父目录，使用排序后的 JSON 原子写入，并把文件权限设为 `0600`。JSON 解码错误直接抛出，不静默覆盖损坏文件。

- [ ] **步骤 4：运行核心检查**

运行：`swift run CodexSwitch5CoreChecks`

预期：备注存储检查和现有检查全部通过。

- [ ] **步骤 5：提交存储与检查**

```bash

```

### 任务二：接入备注状态与生命周期

**文件：**

- 修改：`Sources/CodexSwitch5/AppModel.swift`

**接口：**

```swift
@Published var accountNotes: [String: String] = [:]
@Published var editingNoteAccount: String?
@Published var editingNote = ""

func note(for account: String) -> String?
func beginEditingNote(_ account: String)
func cancelEditingNote()
func saveNote()
```

- [ ] **步骤 1：增加备注状态和存储实例**

存储路径使用：

```swift
private lazy var accountNoteStore = AccountNoteStore(
    url: appDataDirectory.appendingPathComponent("account_notes.json")
)
```

- [ ] **步骤 2：在启动时载入备注**

账号数据载入完成后读取备注文件。读取失败时账号列表仍正常显示，并通过：

```swift
text("无法读取账号备注：%@", error.localizedDescription)
```

显示错误。

- [ ] **步骤 3：实现编辑和保存**

`beginEditingNote(_:)` 填入现有备注；`saveNote()` 去除首尾空白，空内容从字典移除。先保存候选字典，成功后再更新 `accountNotes` 并关闭窗口；失败时保留编辑窗口和输入内容，并显示：

```swift
text("无法保存账号备注：%@", error.localizedDescription)
```

- [ ] **步骤 4：扩展悬浮信息**

`identityHelp(for:)` 在用户名、邮箱或账号文件名之后追加：

```swift
text("备注：%@", note)
```

没有备注时不追加空行。

- [ ] **步骤 5：账号移除后清理备注**

凭据成功移到废纸篓后，从候选备注字典删除对应账号并保存。备注清理失败不能把已经成功的凭据移动报告成“移除失败”，应单独显示备注保存错误。

- [ ] **步骤 6：构建确认模型接口**

运行：`swift build`

预期：`AppModel` 与核心模块编译通过。
