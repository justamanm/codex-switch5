**目标：** 补充 GPT-6 Sol/Luna 的金额计算，并让历史图表柱高直接反映 API 等值金额。

**结构：** 核心模块负责模型价格；统计页使用金额作为图表数值，同时保留 Token 数量文字；使用说明同步说明图表含义。

## 全局约束

- 金额按每百万 Token 的 API 等值价格估算。
- `gpt-6-sol` 使用输入 2、缓存输入 0.2、输出 10 美元的价格。
- `gpt-6-luna` 使用输入 0.1、缓存输入 0.01、输出 0.5 美元的价格。
- 原始 Token 记录和数据库结构不变。
- 自动审查用量不计入 Token 总数和金额。
- 未知模型不套用其他模型价格。
- 文档使用中文；Git 提交信息使用英文。
