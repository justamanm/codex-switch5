# 账号列表应用内拖动实施计划

目标：用应用内手势替换系统 `onDrag/onDrop`，让账号卡片平滑拖动并在松手时一次保存排序。

## 改动文件

- 修改 `Sources/CodexSwitcher/DashboardView.swift`：维护临时顺序、拖动位置和浮层；删除系统拖放委托；将六点把手改为 `DragGesture`。
- 修改 `Tests/CodexSwitcherCoreTests`（如现有排序测试结构允许）：覆盖“拖动仅在松手后保存”的顺序计算。

## 步骤

1. 在 `DashboardView` 增加拖动会话状态：起始顺序、临时顺序、拖动账号名和拖动偏移；账号列表渲染临时顺序优先。
2. 给每个账号行记录列表坐标；按拖动浮层中心点计算目标索引，并只更新临时顺序，使用短动画让相邻账号让位。
3. 将六点把手的 `onDrag` 改为最小移动距离为零的 `DragGesture`：开始时记录状态，变化时更新浮层和临时顺序，结束时一次写入 `accountManualOrder`。
4. 在账号列表上层显示缩小后的完整卡片浮层；原行保持透明占位，取消时恢复原始顺序。
5. 运行核心检查、生产构建，并用测试应用完成跨越多个账号和行间空隙两种拖动验证。
