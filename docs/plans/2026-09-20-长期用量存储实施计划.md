# Codex Switch5 长期用量存储实施计划

> **执行要求：** 按任务顺序实施，每个任务先增加可失败的检查，再完成最小实现并运行全部核心检查。

**目标：** 将持续增长的单次 Token 用量记录和额度历史迁入应用数据目录中的 SQLite，避免长期使用后反复读写全部历史。

**结构：** 新增一个核心 SQLite 存储层，Token 扫描器和额度历史共用同一个数据库文件。

**技术：** Swift 6、macOS 14+、系统 `libsqlite3`、Swift Package Manager、现有 `CodexSwitch5CoreChecks`。

## 全局约束

- 数据库路径固定为 `~/Library/Application Support/Codex Switch5/codex_switch5.sqlite3`。
- 不往数据库写入 access token、refresh token、对话正文或命令输出。
- 数据库结构使用 `PRAGMA user_version`，遇到比当前程序更新的版本时拒绝写入。
- 额度网络查询的自动刷新最小间隔为 60 秒。
- 文档和用户可见文案使用中文。
