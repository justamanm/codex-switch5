# 不可查询账号暂停自动刷新实施计划

## 目标

让不会自行恢复的额度查询失败停止参加自动刷新，同时保留手动恢复入口和临时错误重试能力。

## 修改范围

- `Sources/CodexSwitch5Core/AccountUsage.swift`：保存自动刷新暂停状态，并排除暂停账号的推荐资格。
- `Sources/CodexSwitch5Core/NativeAccountService.swift`：区分登录失效、临时失败和需要暂停的失败。
- `Sources/CodexSwitch5/AppModel.swift`：自动刷新及重置刷新跳过暂停账号。
- `Sources/CodexSwitch5/DashboardView.swift`、`Sources/CodexSwitch5/Localization.swift`：显示暂停状态和手动重试提示。
- `Sources/CodexSwitch5CoreChecks/QuotaRequestChecks.swift`：检查 HTTP 402 暂停、自动跳过和成功解除暂停。
- 中英文使用说明：更新额度刷新规则。
