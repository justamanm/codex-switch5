# 启动与用量刷新修复实施计划

**目标：** 消除启动空账号闪屏，在自动额度刷新关闭时每 5 分钟更新本地 Token 统计，并可靠保留重置卡到期时间。

**实现方式：** `AppModel` 统一管理首次载入状态和两个互斥的刷新任务；Token 扫描继续使用现有增量数据库逻辑。`NativeAccountService` 通过独立的纯规则合并重置卡新旧数据，`QuotaObservation` 把到期时间写入 SQLite 历史。

**技术范围：** SwiftUI、Swift Concurrency、Foundation、现有 SQLite 数据库与 `CodexSwitch5CoreChecks`。

## 全局约束

- 文案使用中文并补齐英文翻译。
- 自动额度刷新开启时不额外启动 Token 定时扫描。
- 自动额度刷新关闭时，Token 扫描间隔固定为 300 秒，不发起网络请求。
- 重置卡详情失败不得覆盖上次已知到期时间。
- 本次不改变数据库表结构，旧 SQLite 额度记录仍可读取。
- 不修改账号凭据格式和账号切换流程。
