## 概述

Codex Switch5 是一款面向 macOS 的 Codex 多账号管理工具。它主要解决 Plus 和 Team 账号触发 5 小时限制后，多个账号难以统一管理的问题；同时提供各账号的 Token 统计和周额度金额预测。

账号信息和凭据只在本机使用，应用不会展示身份令牌内容。

## 下载

请从 [Releases](https://github.com/justamanm/codex-switcher/releases) 下载最新版本，打开 DMG 后将 Codex Switch5 拖入“应用程序”目录。开发中的最新构建可从 [latest Release](https://github.com/justamanm/codex-switcher/releases/tag/latest) 获取。

当前版本使用临时签名。首次运行时，请按住 Control 点击应用并选择“打开”。如果 macOS 仍然阻止运行，请前往“系统设置 → 隐私与安全性”，选择“仍要打开”。

## 主要作用：管理多个 Plus 和 Team 账号

Plus 和 Team 账号出现 5 小时限制后，额度可能很快用完。轮换使用多个账号可以在一定程度上缓解这个问题，但也会带来新的管理负担：每次切换都要手动重新登录，容易忘记每个账号上次剩余的额度，也难以记住不同账号的重置时间。

Codex Switch5 会自动保存并管理这些账号，在一个页面中显示当前账号、5 小时额度、周额度和重置时间。它还会根据各账号当前额度自动判断下一个适合使用的账号，并支持一键切换，减少重复登录、逐个检查和人工比较。

## 次要作用：查看 Token 使用情况和金额预测

Token 统计页面集中展示每个账号在 5 小时周期、周额度周期、当天和本周的 Token 使用情况，包括输入、缓存、输出和推理 Token。

应用还会结合已记录的 Token 用量和额度变化，预测账号完整周额度对应的大致金额。金额按 OpenAI API 等值价格估算，仅用于了解用量规模，不代表 Plus 或 Team 订阅的实际账单。

## 额度历史与使用习惯

在“Token 统计 → 使用习惯”中，可以在本周、本月和最近 30 天之间切换。柱高表示各小时累计使用的 Token，柱顶数字表示该小时出现用量的天数。页面还会合并所有账号的记录，显示每小时平均使用的 5h 额度，以及 5h 额度对应的周额度百分比。首次使用显示数据不足，刷新额度后开始积累；开启自动查询可以持续记录。

每次由本应用发起的额度查询都会保存新查询记录或未取得新数据的记录，应用内账号切换也会记录。历史追加保存在本机 `~/Library/Application Support/Codex Switch5/codex_switcher_usage_history.jsonl`，不会自动删除原始记录；其中不包含认证令牌或脚本输出。历史文件损坏时停止追加并显示错误，不覆盖原文件。首次启动新版时，旧的 Switch5 私有记录会迁移出 `~/.codex/`；Codex CLI 必须读取的凭据和会话不移动。直接在终端运行查询脚本不属于这一阶段的采集范围。

估计只比较同一账号的有效窗口，不使用超过 30 分钟的间隔、查询失败后的间隔、重置或额度回升来估算速度。5h 与周额度的换算由实际变化计算，数据不足时不会默认显示为 15%。

这些记录不能确定实际工作时长或等待时长：额度刷新之间可能包含空闲，账号也可能在其他设备使用。没有消耗不代表不需要使用。不同范围可能暂时显示相同结果，例如现有历史全部位于本周时；页面会显示实际统计起止日期。

## 其他功能

- 自动新增账号，并在登录完成后保存和识别账号。
- 支持手动分组管理，便于将多个 Team 账号放在一起查看和维护。
- 支持按周重置时间、周额度、5 小时重置时间和 5 小时额度进行多条件排序，也可以恢复手动顺序。
- 支持为账号设置别名，清楚标出当前账号和登录失效的账号。
- 支持整体刷新，也可以单独更新某个账号的额度。
- 在额度重置后自动更新账号状态。
- 显示账号的重置卡数量。
- 单个账号查询失败时保留原有信息，避免其他账号受到影响。
- 管理不再使用的非当前账号。
- 支持中文和英文，并可跟随 macOS 系统语言。

## 使用方式

打开应用后，首页会显示当前账号、推荐的下一个账号以及全部账号的额度情况。需要更换账号时，可以使用推荐结果，也可以在账号列表中自行选择。

添加账号时，如果已安装 ChatGPT，应用会使用 ChatGPT 登录；如果只安装了 Codex CLI，应用会提示你在终端运行 `codex login`，并在登录后识别新账号。如果中途取消，应用会恢复添加前使用的账号。

## 使用说明

- 增加账号需要安装 ChatGPT 或 Codex CLI；两者都未安装时，Codex Switch5 会在改动任何账号文件前停止。
- 检测到 Codex CLI 时，切换或增加账号前请先退出正在运行的 CLI 会话，并在应用提示后重新打开。
- 未安装 ChatGPT 时仍可切换已有账号，应用会跳过自动打开 ChatGPT。
- 添加账号期间请保持 Codex Switch5 运行，以便完成登录或取消后的恢复。
- 账号信息和凭据只在本机使用，应用不会展示身份令牌内容。
